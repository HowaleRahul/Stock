Start the project
=================

Run these commands in PowerShell from the project folder. The Python launcher
is `start.py`; this guide does not depend on the deleted `start.bat`,
`start.ps1`, or `start.txt` files.

First-time setup
----------------

1. Create the Python environment and install dependencies:

   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

2. Install frontend dependencies:

   cd frontend
   npm install
   cd ..

3. Create `.env` from the sample if you do not already have one, then edit it.
   Set `POSTGRES_PASSWORD` and make sure the password in `DATABASE_URL` matches:

   if (!(Test-Path .env)) { Copy-Item .env.example .env }

4. Start the database:

   docker compose up -d

Start the project next time
---------------------------

From the project folder, run:

   docker compose up -d
   .\.venv\Scripts\python.exe start.py

Keep the terminal open while using the app. Press Ctrl+C in that terminal to
stop the backend, paper trader, and frontend.

Open the dashboard at the URL printed by Vite (usually
http://localhost:5173/app/). API docs are at http://localhost:8000/docs.
